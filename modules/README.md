# Native modules

Native work for THIRTY lives here.

This directory will eventually contain focused Swift/Kotlin Expo modules and, later in the challenge, JSI/Nitro/C++ experiments. Each module should have a small typed JavaScript API, platform notes, and a demo inside `apps/showcase`.

Do not move code native just to make an experiment look more advanced. Native code should solve a platform-access, latency, throughput, or rendering problem that is easier to explain after the move than before it.
